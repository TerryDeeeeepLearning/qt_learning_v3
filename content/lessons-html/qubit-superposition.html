為什麼要學這個

前四課都是工具，從這裡開始是物理

複數、內積、Hermitian、酉算子都準備好了。這一課正式進入主題： 量子位元到底是什麼、疊加態怎麼寫、以及一個很多人搞錯的關鍵區別—— 疊加不等於「不確定」。

核心概念

量子位元的一般形式

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle,\qquad |\alpha|^2+|\beta|^2=1$$

這就叫疊加態——量子位元不是「非 0 即 1」，而是同時帶有 $|0\rangle$ 和 $|1\rangle$ 兩個分量，直到被測量（下一課）才會塌縮到其中一個。

📐 推導：兩個複數 = 4 個實數，為什麼 Bloch 球只需要 2 個角度？
起點：4 個自由度 $\alpha,\beta$ 各是一個複數，各有實部與虛部 → 總共 4 個實數自由度。
限制 1 · 歸一化 $|\alpha|^2+|\beta|^2=1$ 是一條方程式，砍掉 1 個自由度 → 剩 3 個。
限制 2 · 全域相位不影響物理 把整個態同乘 $e^{i\varphi}$： $$e^{i\varphi}|\psi\rangle = e^{i\varphi}\alpha|0\rangle + e^{i\varphi}\beta|1\rangle$$ 測量機率是 $|e^{i\varphi}\alpha|^2 = |e^{i\varphi}|^2|\alpha|^2 = |\alpha|^2$， 完全沒變。所以 $|\psi\rangle$ 和 $e^{i\varphi}|\psi\rangle$ 在物理上是同一個態， 再砍掉 1 個自由度 → 剩 2 個。
結果：參數化成兩個角度 利用這個自由度把 $\alpha$ 轉成非負實數，得到標準形式： $$|\psi\rangle = \cos\frac{\theta}{2}|0\rangle + e^{i\phi}\sin\frac{\theta}{2}|1\rangle$$ 剛好對應球面上一個點：$\theta$ 是緯度、$\phi$ 是經度。這顆球就是 Bloch 球。
為什麼是 $\theta/2$ 不是 $\theta$？ 因為要讓 $\theta$ 從 $0$ 走到 $\pi$（北極到南極）時， 態剛好從 $|0\rangle$ 走到 $|1\rangle$。若用 $\theta$，走半圈就會回到原態， 球面會被「繞兩次」。用 $\theta/2$ 才能讓球面與量子態一對一對應。
互動探索

Bloch 球：把抽象的疊加態變成看得見的箭頭

關鍵實驗 · 請務必自己動手做

把 θ 固定在 π/2（赤道），然後只拖動 φ。你會看到：

  • 量子態一直在變（機率幅的虛部不斷變化）
  • 但 P(0) 和 P(1) 永遠停在 50% / 50%，完全不動

這就是「相位在單獨測量時是隱形的」最直接的證據。 $|+\rangle$（φ=0）和 $|-\rangle$（φ=π）是兩個明確不同的量子態， 在後續電路裡行為完全不同，但單獨測量它們卻給出一模一樣的統計結果。 第 11 課會告訴你怎麼把這個隱形的資訊「逼」出來。

觀念釐清

疊加 ≠ 「電腦還不知道是 0 還是 1」

最常見的誤解，是把疊加態當成「機率上不確定，只是我們還沒看」。這是錯的，原因如下：

$$|+\rangle = \tfrac{1}{\sqrt2}(|0\rangle+|1\rangle),\qquad |-\rangle = \tfrac{1}{\sqrt2}(|0\rangle-|1\rangle)$$

兩者測量結果完全相同（各 50%）。但如果對它們各做一次 $H$ 閘：

$$H|+\rangle = |0\rangle \quad\text{（100\% 測到 0）},\qquad H|-\rangle = |1\rangle \quad\text{（100\% 測到 1）}$$

如果它們真的只是「50/50 的古典隨機」，那做完 $H$ 之後結果應該還是隨機的。 但實際上 結果變成 100% 確定，而且兩者相反—— 這代表那個「看不見的相位」確實攜帶了真實的物理資訊。 古典機率沒有相位，也就沒有這種行為。

實際應用

不同硬體，同一套數學

真實的量子位元有很多種物理實現：超導電路、離子阱、光子等。 不同平台的 $|0\rangle$、$|1\rangle$ 對應不同的物理自由度（例如超導電路裡是不同能階）， 但數學描述完全一樣，都是這一課的 $\alpha|0\rangle+\beta|1\rangle$。

這也是為什麼量子計算的理論論文通常不指定硬體平台——數學形式是共通的。

重點回顧

小結

  • 量子位元狀態 $|\psi\rangle=\alpha|0\rangle+\beta|1\rangle$，$|\alpha|^2+|\beta|^2=1$
  • 4 個實數自由度，扣掉歸一化與全域相位後只剩 2 個，剛好是 Bloch 球的 $(\theta,\phi)$
  • 疊加的關鍵不是「不確定」，而是帶有可以干涉的相位
  • $|+\rangle$ 與 $|-\rangle$ 測量統計相同，但經過 $H$ 之後行為完全相反
