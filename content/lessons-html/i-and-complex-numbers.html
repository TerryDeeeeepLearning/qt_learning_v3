為什麼要學這個

把 $i$ 從「一個符號」變成「一個動作」

論文裡每個量子態都寫成 $\alpha|0\rangle + \beta|1\rangle$，其中 $\alpha,\beta$ 是複數。 如果你只把 $i$ 記成「$\sqrt{-1}$」這個代數技巧，之後看到相位 (phase)、干涉 (interference) 這些字眼時會完全建立不起直覺。

這一課只做一件事：讓你看見 $i$ 其實是一個旋轉 90 度的動作。

核心概念

複數 = 平面上的箭頭 = 旋轉

一個複數 $z = a + bi$ 可以畫成平面上的點 $(a,b)$。但更有用的看法是極座標形式：

$$z = re^{i\theta} = r(\cos\theta + i\sin\theta)$$

$r$ 是長度（模），$\theta$ 是角度（相位）。乘上 $e^{i\theta}$ 這個動作， 幾何上就是「把箭頭轉 $\theta$ 角度，長度不變」。

📐 推導：為什麼「乘 $i$」剛好是轉 90 度？
Step 1 · 從尤拉公式出發 $$e^{i\theta} = \cos\theta + i\sin\theta$$ 這是整個複數幾何的樞紐，把「指數」和「三角函數」接在一起。
Step 2 · 代入 $\theta = \pi/2$ $$e^{i\pi/2} = \cos\frac{\pi}{2} + i\sin\frac{\pi}{2} = 0 + i\cdot 1 = i$$ 所以 $i = e^{i\pi/2}$——「乘上 $i$」就是「乘上 $e^{i\pi/2}$」，也就是逆時針轉 90 度。
Step 3 · 解釋 $i^2 = -1$ $$i^2 = e^{i\pi/2}\cdot e^{i\pi/2} = e^{i\pi} = \cos\pi + i\sin\pi = -1$$ 轉兩次 90 度 = 轉 180 度 = 方向完全反過來。 「$i^2=-1$」不再是一條要背的規則，而是一個幾何事實。 上面的互動元件按四次「× i」就會轉回原點，因為 $i^4 = e^{2\pi i} = 1$。
連結到量子力學

相位差 → 干涉 → 量子演算法的動力來源

量子態的係數（機率幅）是複數，其中的角度部分稱為相位。 兩個量子態相加時，相位決定它們是互相加強還是互相抵消——這就是量子干涉。

手算範例 · 相位如何決定加強或抵消

考慮兩個機率幅相加，看相位差如何徹底改變結果：

$$\frac{1}{\sqrt2}\left(1\right) + \frac{1}{\sqrt2}\left(e^{i\cdot 0}\right) = \frac{2}{\sqrt2} = \sqrt2 \quad\text{（同相位 → 加強）}$$
$$\frac{1}{\sqrt2}\left(1\right) + \frac{1}{\sqrt2}\left(e^{i\pi}\right) = \frac{1}{\sqrt2}(1 - 1) = 0 \quad\text{（相位差 }\pi\text{ → 完全抵消）}$$

兩個式子的「大小」完全一樣（都是 $1/\sqrt2$），只有相位不同， 結果卻從「$\sqrt2$」變成「$0$」。量子演算法的設計精髓，就是安排相位， 讓錯誤答案互相抵消、正確答案互相加強。

如果係數只能是實數，就沒辦法描述這種依角度而定的加強／抵消行為—— 這正是量子計算比古典計算「多出來」的自由度。

重點回顧

小結

  • 複數 $z = re^{i\theta}$ 可以理解成「長度 $r$、角度 $\theta$ 的箭頭」
  • 乘上 $i$ = 逆時針轉 90 度，這解釋了 $i^2 = -1$、$i^4 = 1$
  • 量子態的複數係數帶有相位，相位差決定了干涉是加強還是抵消
  • 後面每一課的「相位」討論，源頭都在這裡
